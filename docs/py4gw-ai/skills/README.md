# Py4GW AI Workflow Guides

Status: current
Scope: task-oriented engineering workflows for Py4GW contributors and agents
Authority: `AGENTS.md`, the owning current source, and the Py4GW AI guidance

Each child directory contains one workflow guide named `SKILL.md`. The guide
helps a contributor identify the appropriate sources, mutation boundary, and
verification for a recognizable recurring task. These are documentation
workflows: they do not affect the injected runtime, native DLL, or build.

Use `../skill-catalog.md` to choose a workflow and
`../skill-authoring-guide.md` to create or revise one.
